Points Forts Architecturaux

🔄
Transaction & Rollback

Si la création échoue sur Odoo après avoir réussi sur LDAP, le système annule automatiquement la création LDAP pour maintenir la cohérence (Pattern Command).

⚡
Asynchronisme

L'API répond instantanément à MidPoint. Les tâches longues (Odoo, validation humaine) sont empilées dans Redis et traitées par des workers en arrière-plan.

🧠
Intelligence Artificielle

L'agent IA traduit le langage naturel en configurations YAML complexes et explique les erreurs d'audit via la recherche vectorielle (Qdrant).

🐳
Déploiement Dockerisé

Environnement complet encapsulé via docker-compose (Gateway, BDD, Broker, Keycloak), assurant une reproductibilité parfaite.

Sécurité & Déploiement

Authentification Centralisée

Protection de tous les endpoints API via vérification de tokens JWT délivrés par Keycloak (OIDC). Contrôle d'accès basé sur les rôles (RBAC).

Protection des Données

Secrets et mots de passe (AD, Odoo) isolés via variables d'environnement (`.env`). Validation stricte des payloads entrants avec Pydantic.
