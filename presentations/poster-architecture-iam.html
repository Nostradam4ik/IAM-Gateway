🔄 Transaction & Rollback

En cas d'échec sur un système cible (ex: Odoo), le système annule automatiquement les créations précédentes (ex: LDAP) pour garantir la cohérence des données.

⚡ Traitement Asynchrone

Réponse immédiate à MidPoint. Les opérations longues ou nécessitant une validation humaine sont mises en file d'attente (Redis) et traitées en arrière-plan.

🛡️ Sécurité & OAuth2

Authentification de tous les endpoints via Keycloak (JWT). Isolation stricte des secrets d'infrastructure via variables d'environnement.

🐳 Infrastructure Docker

Déploiement complet via docker-compose incluant l'API, les bases de données (Postgres, Redis, Qdrant) et l'Identity Provider (Keycloak).
